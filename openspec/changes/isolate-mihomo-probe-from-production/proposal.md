# Proposal

## Why

2026-10-12 的周期探测覆盖生产 Mihomo 配置并重启实例，移除了业务监听；隔离复现证明该路径会制造连接失败。随后实际 Mihomo v1.19.1 的非强制整份加载也被证实会短暂拒绝新连接，必须同时隔离探测、替换周期发布方式，并补齐旧节点删除前的客户端迁移与排空。

## What Changes

- 复用现有 Mihomo 二进制，以独立临时配置、数据目录、回环探测监听和 Unix Controller 启动短生命周期探测进程；代理切换和探测请求仅使用该实例。
- **BREAKING** 删除探测初始化覆盖生产配置及两处自动 `systemctl restart mihomo`；生产 Controller 不可用时本轮失败，不再通过重启恢复。
- 对完整更新持有单实例锁，明确启动就绪、执行期限、取消与进程回收；探测基础设施失败不得误发布为空出口。
- **BREAKING** 首次采用用户已接受的一次维护暂停，将直绑节点监听迁移为固定回环端口槽、独立 file 代理提供器及 reject 空槽；长期保持单生产实例。日常发布与恢复只刷新提供器，禁止整份配置加载、生产 stop/restart 和连接强制关闭。
- 按订阅来源保存最后有效完整快照；成功差分移除来源引用，失败保留。用完整连接定义归一化节点身份；改名、排序和重复来源不改变身份，连接参数修改按新节点加入、旧节点退役处理。
- 新出口先验证并加入提供器，注册表最后提交。对缓存客户端、模型流、验证码求解/补货及领取、安装、额度查询等托管消费者实施实际操作引用和版本栅栏；新业务转同大区替代，旧操作完成后才删除物理节点、将槽变为 reject 并允许同区复用。
- 保留现有注册表 `updated_at` / `regions` 与 URL 列表，增加版本及槽位身份元数据；保护提供器、生命周期、扫描结果、环境代理项和注册表的恢复记录，生产基础配置作为只读基线。显式固定引用、未知消费者、无替代或无有效排空确认均阻止回收并说明原因。
- 分别验收首次维护迁移与日常完整周期。日常必须覆盖真实 Mihomo TCP/SSE、新请求迁移、订阅增删改、取消、过期确认及失败恢复，不以接口成功、旧流存活或隔离原型代替全链路结果。实际额度、验证码算法及公开错误协议仍不属于修复范围。

## Capabilities

### New Capabilities

- `isolated-egress-probing`：临时探测实例的资源隔离、受管生命周期、互斥及基础设施失败栅栏。

### Modified Capabilities

- `egress-region-pinning`：改为固定槽提供器刷新，补全订阅成员差分、一次维护迁移、版本发布、节点退役及安全复用；保留账号地域与百位段边界。
- `account-client-pool`：补全缓存客户端对已提交出口版本的感知、操作引用、旧客户端排空及不关闭在途操作的回收契约。

## Impact

- 实施影响 `scripts/mihomo_auto_probe.py`、`app/client_pool.py`、`app/routes/gateway.py`、`app/captcha.py`、`app/claim.py`、`app/install.py`、`app/quota.py` 及应用生命周期的最小协调入口。复用现有连接池、流关闭回调、串行探测和标准库文件机制；不新增数据库、依赖、常驻第二生产服务或通用协调框架。
- 显式托管端口、全局代理候选和验证码配置获取等直接消费者必须服从同一准入栅栏；未托管代理不自动改写。现有 timer 保留调度方式和频率，oneshot 补齐有限执行和子进程回收；无依据不修改账号库、额度或并发参数。
- 扩展既有客户端、验证码、领取、探测与网关集成用例；同步 `docs/development/01-architecture.md`、`docs/development/06-dev-guide.md`、`docs/testing/05-acceptance.md` 的相关小节，代码、中文注释及提交保持原风格。
- 交付覆盖正式实施、实际 Antigravity CLI 验收与已授权的 VPS 发布：先隔离验收，再按 Git 推送、VPS 原目录快进和制品哈希核对发布；首次维护同时部署网关协议与代理结构，全部验收通过前不恢复故障 timer。实际进度与运行证据以 tasks 和 implementation 为准，规划审查不代表实施完成。
- 维护前必须重新核对在途请求、后台任务及共享消费者；“当前不用”不是服务已停止的证据。实际路径、地址、订阅、鉴权和节点秘密来自已有配置，规划与外发审查包不含敏感值；私有回退副本保留权限，回退旧缺陷脚本时 timer 保持暂停。
- 目标是消除本脚本制造的生产中断。实际额度耗尽、外部节点或上游故障仍按现有机制处理；短验证码参数的 SDK 内部分支未由历史证据证明，不将其作为已修复结果。
