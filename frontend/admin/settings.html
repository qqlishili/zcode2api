活动监控与 Bark 通知
支持粘贴裸 Key（如 abcd1234efgh）或客户端提供的完整链接（如 https://api.day.app/abcd1234efgh/）。输入框显示掩码，未改动保存不会覆盖原值。
默认官方服务 https://api.day.app。若使用自建 Bark 服务器可在此覆盖。
后台单哨兵自动检测官方新赠送活动的周期。默认 1800 秒（30分钟），设为 0 关闭自动巡检。
开启后，哨兵探测到新活动时，自动以单并发顺序串行（带随机抖动延时保护验证码池）为全池可用账号领券，抢领战报将合并推送至 Bark。
使用说明
· 在「账号池」粘贴 Coding Plan JWT 或 API Key 即可加入轮询。
· 请求按 round-robin 分发；某账号额度用完会自动切到下一个账号。
· 账号额度、状态在「账号池」页实时刷新展示。
· 对话端点：/v1/messages（兼容 Anthropic Messages 协议）。
