支持粘贴裸 Key（如 abcd1234efgh）或客户端提供的完整链接（如 https://api.day.app/abcd1234efgh/）。输入框显示掩码，未改动保存不会覆盖原值。
默认官方服务 https://api.day.app。若使用自建 Bark 服务器可在此覆盖。
后台单哨兵自动检测官方新赠送活动的周期。默认 1800 秒（30分钟），设为 0 关闭自动巡检。
开启后，哨兵探测到新活动时自动顺序为全池账号领券，合并推送战报至 Bark。

网关集成与端点说明
POST /v1/messages
· 协议兼容：完全兼容 Anthropic Messages 协议（/v1/messages），支持直接接入 Claude Code、Cursor 等客户端。
· 账号池轮询：在「账号池」录入多个 Coding Plan JWT 或 API Key 即可加入轮询调度，额度耗尽或限流时自动故障转移到下一有效账号。
· 实时可观测：可在「请求监控」实时查看请求吞吐、成功率、首字响应延迟（TTFB）与 Token 消耗走势。
